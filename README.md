# Projeto Drupal

Projeto desenvolvido durante o Programa New Thinkers — edição Drupal (2024).

## Sobre o projeto

Projeto desenvolvido durante o bootcamp utilizando Drupal, com foco na criação e organização de conteúdos dinâmicos.

## Funcionalidades

- Exibição de conteúdos dinâmicos
- Organização de conteúdos por categorias
- Filtros personalizados por categoria

## Tecnologias

- Drupal
- PHP
- Composer
- Docker
- DDEV

## Sobre a experiência

O projeto fez parte da minha participação no Programa New Thinkers, edição Drupal, em 2024, contribuindo para minha experiência prática com desenvolvimento web e gerenciamento de conteúdo.
